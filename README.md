# Template Selector Generator
The initial goal of this project is to provide simplified use of WPF Template Selector to require less code and boilerplate when using the selectors that are shared between multiple locations in the code.

My use case was to extend ActiproSoftware's [WPF-Library](https://github.com/Actipro/WPF-Controls) to offer a more simplified implementation of [bar menus](https://www.actiprosoftware.com/products/controls/wpf/bars) through MVVM, but this is of course available for non-Actipro users as well.
